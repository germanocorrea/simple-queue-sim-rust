# Simple Queue Simulator

Recreation in rust of the simulator made in [germanocorrea/simple-queue-simulator--pucrs](https://github.com/germanocorrea/simple-queue-simulator--pucrs). The original was developed as part of class assignments for the Simulation and Analytical Methods class. This remake is to exercise myself in rust.
